# 灵思对标研究开源版 · v0.6.0

本地登录抖音 → 读取账号作品 → 批量下载转写 → AI 接口逐条拆解与账号研究 → 查看与导出。

本版所有研究改用用户自己配置的 AI API，在网页中直接执行。不需要安装额外 AI 命令行、复制研究指令或切换到其他对话。

## 安装启动

准备 Python 3.11+ 和 Edge 或 Chrome。基础网页只依赖 Python 标准库。

1. 双击 **安装采集组件.cmd**，将 Playwright 安装在本项目 `.venv`。
2. 需要本地转写时，双击 **安装转写组件.cmd**，安装 faster-whisper；在任务中心准备模型。首次下载模型需要网络和磁盘空间。
3. 双击 **启动灵思.cmd**，打开 **http://127.0.0.1:5030**。
4. 打开「设置与帮助 → AI 接口配置」，填写并测试接口，即可在网页内研究。

直接启动：`python app.py --port 5030 --no-browser`。自定义数据目录：`python app.py --port 5030 --data-dir "D:/LinsiData"`。启动器优先使用 `.venv`，程序仅监听本机。升级时保留实际使用的数据目录；安装新依赖后重新启动。

## 配置 AI 接口

支持 **OpenAI Chat Completions 兼容协议**，请求目标为 Base URL 后的 `/chat/completions`。设置中提供 DeepSeek、OpenAI、本机兼容服务和自定义地址预设；实际可用模型以你的服务商和账号权限为准。

| 字段 | 填写方式 |
| --- | --- |
| 接口地址 | 例如 `https://api.deepseek.com`、`https://api.openai.com/v1`，或服务商给出的兼容根地址。填完整 `/chat/completions` 地址也会归一化。 |
| API Key | 用户自己的服务商密钥；无密钥本机模型可留空。不会从其他软件自动读取凭据。 |
| 模型名称 | 填写服务商模型 ID；也可先保存地址和密钥，再点「获取模型列表」选择。列表接口不支持时手动填写。 |
| 单次响应超时 | 30～600 秒，默认 180 秒；网络连续无响应 30 秒会报连接超时。 |

「保存并测试连接」会发送一条短测试消息，使用自己的 API 额度。通过后确认作品清单即自动排队分析。未配置时采集和转写仍可进行，研究清楚显示待配置；配置后在原批次或报告页点击「开始 / 重试 AI 研究」。

密钥保存在本机数据目录的 `ai-config.json`，网页只显示是否已保存，不回显明文，不写入浏览器缓存、日志或导出包。留空保存可保留旧密钥；更换接口地址时必须重新填写该服务的密钥，或明确清除。运行数据和备份应私有保存。远程服务仅允许 HTTPS；本机环回地址可用 HTTP。不跟随接口跳转转发密钥。

DeepSeek 官方接口默认使用「快速研究」生成基础报告，也可在设置中选择深度思考或服务商默认。其他兼容接口不附加此参数。深度思考的等待通常更长，程序只展示响应状态和最终正文，不把思考内容当成报告。参数依据见 [DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

兼容协议参考：[DeepSeek 官方接口说明](https://api-docs.deepseek.com/)、[Chat Completions 请求格式](https://api-docs.deepseek.com/api/create-chat-completion/)。暂不支持仅有 Anthropic Messages 或 Responses 协议的地址，请使用服务商的 Chat Completions 兼容地址。

## 第一次研究

1. 首次进入自动建立「我的工作台」，不必填写定位表单。点击连接抖音，在本工具专用浏览器扫码和完成验证；识别自己账号后自动同步作品。它是本地浏览器连接，不是开放平台 OAuth 授权。
2. 粘贴对标主页或作品分享链接，读取页面正常返回的作品与互动。可继续加载更多作品；平台验证、网络和页面变化会影响采集，未取得资料不会用演示数据冒充。
3. 在账号页点击「首次账号研究」，或者多选账号分别研究。默认推荐每账号 6 条，可改为 3/10 条或手选；显示近期发布、本批点赞/评论/收藏靠前等公开理由，仅代表当前已读取样本。
4. 确认作品清单，可选每条最多 30 条可见评论。已有视频和全文复用，视频下载后在本地转写，图文不送入语音识别；缺少正文时提示补充。每账号最多 30 条、每批最多 100 条、最多 10 个账号。
5. API 自动逐条拆解，再生成同账号初步结论。单个作品或账号失败不阻塞其他账号；可以重试未完成项，或先用成功作品继续。补齐样本会生成新汇总，旧来源和报告保留。
6. 在研究页查看逐条拆解和账号结论，阅读、复制、导出完整成果。来源以 `service_account_key`、`sec_uid`、`aweme_id` 绑定，不按标题猜测，不跨工作台混用。

作品/素材多选后操作条立即出现，支持下载、转写、评论采集、逐条拆解和账号研究。单条作品在预览中也可创建拆解；已有待处理报告支持 API 继续研究。无需重新导入旧数据。

报告页「开始当前报告 / 重试当前报告」仅将这份报告加入队列，不重新开始整批。「停止当前报告」也不取消其他作品。需要继续整个账号时，点击「查看整批进度 / 恢复整批」；已完成拆解复用，只处理剩余作品后生成账号汇总。单份手动请求在当前网络请求结束后优先执行。

## 预览、进度与失败恢复

点击封面或标题，弹窗内直接播放视频、查看完整文案、采集和导出评论；支持上一条/下一条、播放拖动、全文复制和 TXT 导出。图文展示可取得的图片与评论。封面和头像缓存在本机。

下载使用真实大小，转写使用已识别音频时长显示阶段进度；总量未知时显示等待状态。AI 流式响应显示实际收到的正文字数，不伪造时间百分比；服务不支持流式响应时等待完整正文后校验。空回答、仅推理过程、超时、权限不足、限流、截断、无效格式、来源 ID 缺失均不会标为研究完成。

批次、子任务和报告持久保存，关闭网页不取消任务。可停止本批或单份报告，停止网络等待最多需当前读取超时结束；服务重启后需手动恢复，避免重复收费。没有自动重发付费请求。重试复用已有文案和拆解，失败不删除素材。重新转写成功后才更新文案，失败保留旧正文与文件。

研究输出范围是有来源的基础观察：开头、用户问题、结构、表达、主题共性、样本互动与评论问题，以及可学习的方法。无画面只分析文字，样本不是全账号规律；事实、推断和未知分开。来源中的指令不改变研究任务。

## 数据、导入与公开范围

- 数据位于 `.local/` 或启动时指定的目录：SQLite 台账、浏览器登录资料、视频、模型、评论、封面、研究来源和报告。
- 用户主动开始研究后，所选文案、已采集评论与工作台研究定位会提交给配置的 API 服务。视频下载与语音识别仍在本机；本工具不自动上传灵思云端，不默认采集遥测。
- 多工作台切换时分别加载资料。演示资料均为虚构，不能当作真实经营证据；演示账号不能连接真实采集。
- 支持 JSON 账号作品导入、TXT/SRT/VTT 文案导入、Markdown 报告手工导入。接口见 [接口与导入](docs/接口与导入.md)。
- 公开本地采集、转写、评论、透明样本推荐、API 基础研究与完整成果导出。持续监控、机会评分、完整选题脚本、语言学习、发布复盘、剪辑编排和商业后台保留在云端。

## 验证与打包

测试必须使用临时 `LINSI_DATA_DIR` 和 `KNOWLEDGE_VAULT_DIR`。运行 `python -m unittest discover -s tests -v`；对 static 下全部 JS 执行 `node --check`；运行 `python scripts/validate_release.py` 和 `python scripts/package_release.py`。

打包只使用 release-files.json 白名单，附 SHA-256 清单，不包含运行数据、密钥、模型、浏览器资料、测试产物或其他项目文件。解压后应验证空数据库启动。模拟服务测试不等于真实服务商付费模型或抖音实时采集验收。

代码使用 MIT 许可证，品牌不授予官方身份；可选依赖由用户安装，遵循相应许可证。当前主要以 Windows + Edge 验收，其他系统可用 Python 启动并自行安装依赖。


## 版本更新

灵思启动后自动检查 GitHub 正式版本。有新版时，可在设置页查看更新内容、下载更新，任务完成后点击“更新并重启”。程序会备份并保留本地账号、作品和 API 配置；更新失败时恢复旧版。也可以稍后提醒或忽略此版本。网络不可用不影响本地功能。
