# 自动剪辑演示素材与许可

用户授权复用其官网已有的公开演示。auto-edit-demo.mp4 和 auto-edit-demo.webp 为官网原始素材的逐字节副本；未生成、重剪或改配音。

人物为 AI 生成的虚构成年男性，视频 5 秒、无音轨。字幕、图表与轨道是独立展示包装，非对口型转写、产品指标或实际剪辑执行记录。视频使用官网已生成的 LivePortrait 输出；本项目不包含模型、渲染代码或检测器。

演示只提供播放、效果切换和样式预览，不包含商业剪辑接口、上传、生成或成片导出。自动剪辑通过云端试用入口了解，本地提供交互动效展示。
