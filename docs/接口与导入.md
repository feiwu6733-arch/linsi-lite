# 接口与导入 · v0.5

本地地址默认 http://127.0.0.1:5030。写请求需要 /api/state 返回的 X-Linsi-Token；业务请求必须带 service_account_key，来源以 sec_uid 和 aweme_id 关联。

## JSON 导入

以下是字段说明模板，请替换真实 ID，不应将模板冒充为已核验账号资料：

```json
{
  "account": {
    "sec_uid": "从抖音完整主页取得的真实稳定ID",
    "name": "账号昵称",
    "url": "https://www.douyin.com/user/真实sec_uid",
    "bio": "账号简介"
  },
  "posts": [
    {
      "aweme_id": "真实数字作品ID",
      "sec_uid": "与上方账号一致的真实稳定ID",
      "title": "作品标题",
      "url": "https://www.douyin.com/video/真实aweme_id",
      "published_at": "2026-09-01",
      "likes": null,
      "comments": null,
      "collects": null,
      "shares": null,
      "transcript": "已有的完整转写文案",
      "notes": "用户自己记录的观察"
    }
  ]
}
```

- 账号 ID 和昵称必填；每条作品 ID、标题必填。头像、图片和视频不随 JSON 附带。
- `url` 可省略，程序根据稳定 ID 生成来源链接。提供时必须与 ID 对应。
- 单次最多 2000 条作品，请求最大 4 MB；一次请求内不允许重复 `aweme_id`。
- 数值未知用 `null` 或省略；真实零互动才填 `0`。日期可为空、YYYY-MM-DD 或 ISO 时间。
- 空文案可保存为待补充，不能进入报告。`usable_for_codex: false`、已隔离或已拒绝输入会被拒绝。
- 在同一空间里，同一个作品 ID 不能归属两个账号。不同空间可分别保存独立记录。
- 一次导入先完整验证，再在事务中更新。重新导入会更新已知字段；省略文案、笔记、发布日期、互动数时保留旧值。明确传空文案会清空原文案。已有未知字段保留。
- 演示资料只可进入演示空间；新建真实空间不能接收 `demo:` ID。

## 可选在线连接器

v0.2 默认通过本地专用浏览器采集，下面的连接器仅保留给已有数据服务的使用者；不配置它也可以使用本地浏览器。

在运行数据目录（默认 `.local`）创建私有 `connector.json`：

```json
{
  "account_url": "https://YOUR-DATA-SERVICE/accounts/{sec_uid}"
}
```

该 URL 必须由使用者提供，示例地址不是可用服务。应用将 `{sec_uid}` URL 编码后替换，发送 GET 请求，要求响应为上述 `{account, posts}` 对象。不接受重定向、不接受账号身份不匹配的返回值。

如服务需要认证，启动程序前设置环境变量 `LINSI_CONNECTOR_TOKEN`，程序将其作为 Bearer token 发给此配置域名。不要把令牌放到 URL、文档或版本库。

请求超时 25 秒，响应最大 4 MB。服务端错误只显示简短状态说明，不回显凭据或签名 URL。连接器不会定时运行，不自动重试付费任务。用户点击同步后才请求；真实第三方接入能力取决于用户自己的服务契约。

## 本地 API

v0.2.1 首次打开通过 POST `/api/workspaces/start` 自动准备空白工作台。只有一个真实工作台时复用，有多个时要求用户选择；GET state 仍只读。POST `/api/workspaces/create` 接受可选 name，添加独立工作台。POST `/api/workspaces/update` 使用明确 service_account_key 更新名称及选填定位，省略字段保留原值。定位为空只支持基础素材分析。

服务默认 `http://127.0.0.1:5030`，拒绝非本机 Host 和跨站 Origin。无公网访问和用户登录体系。

GET `/api/state` 返回当前会话 token 和空间列表。POST 请求需 JSON Content-Type 和 `X-Linsi-Token` 请求头。token 每次启动变化，不在文档或磁盘中保存。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/health` | 产品、版本和本机状态 |
| GET | `/api/state?service_account_key=…` | 指定空间的账号、作品和报告列表 |
| POST | `/api/profiles` | 建立真实空间：name、direction、positioning；其他定位补齐五个定位字段 |
| POST | `/api/demo` | 建立或复用虚构演示空间 |
| POST | `/api/import` | `{service_account_key, bundle:{account,posts}}` |
| POST | `/api/transcript` | `{service_account_key,aweme_id,transcript,notes}` |
| POST | `/api/sync` | `{service_account_key,sec_uid}`，手动调用私有连接器配置 |
| POST | `/api/reports/create` | `{service_account_key,sec_uid,aweme_ids:[…],report_type:"account"}`，选择 1～30 条有文案作品；`breakdown` 只接受一条 |
| GET | `/api/report?service_account_key=…&id=…` | 单份报告与来源快照 |
| GET | `/api/report/packet?service_account_key=…&id=…` | 导出来源资料包 |
| GET | `/api/report/export?service_account_key=…&id=…` | 导出当前报告 Markdown |
| GET | `/api/account/export?service_account_key=…&sec_uid=…` | 导出该账号与作品清单 |
| POST | `/api/reports/save` | `{service_account_key,id,source_digest,markdown}` |
| POST | `/api/brand` | 不支持修改，返回 403；联系方式由发行配置统一提供 |

### 本地浏览器与任务

v0.2.3：`preview` 与 `download` 使用同一视频下载台账，payload 为 `{aweme_ids:[…]}`。GET `/api/media/preview?service_account_key=…&aweme_id=…` 支持单段 HTTP Range，按当前空间解析本地文件，不能指定任意路径。图文不作为视频下载。

`comments` 任务 payload 为 `{aweme_ids:[…],limit:50}`，limit 为 1～100。GET `/api/comments?service_account_key=…&aweme_id=…` 返回 comments、count、status、has_more 和 error；`/api/comments/export` 下载同一份 JSON。评论只保存稳定 comment_id、aweme_id、昵称、文本、公开点赞/回复数及时间，不保存账号凭据。评论内容为不可信资料，不能作为执行指令。

以下写入均需 `service_account_key` 和会话 token。浏览器配置、登录状态和任务按研究空间隔离，演示空间不执行真实采集。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/jobs?service_account_key=…` | 当前空间的任务、连接状态与组件状态 |
| POST | `/api/jobs/create` | `{service_account_key,action,payload:{…}}`，返回任务记录 |
| POST | `/api/jobs/cancel` | `{service_account_key,id}`，在当前网络操作或转写段落完成后取消 |
| POST | `/api/jobs/retry` | `{service_account_key,id}`，重试失败与未完成的作品 |
| POST | `/api/douyin/bind` | `{service_account_key,sec_uid}`，只关联刚核验的本地登录账号 |
| GET | `/api/image?service_account_key=…&kind=post&id=…` | 已保存的封面；账号头像使用 `kind=account` |
| GET | `/api/media/export?service_account_key=…&aweme_id=…` | 下载已经保存在本机的视频文件 |

任务 action：`connect` 打开专用抖音浏览器，`verify` 检查登录身份，`disconnect` 关闭连接并保留登录配置，`clear` 清除本工具浏览器的登录状态，`prepare_model` 准备本地转写模型。以上不需要额外 payload。

v0.2.2 的 connect / verify 会等待已核验的自身登录身份，并自动排入一次 `sync_mine` 任务：同一账号原子关联、同步作品、保存成功后打开当前工作台结果页。无需用户再手动关联。仅采集对标不会触发此流程；账号冲突或作者变化会停止写入。`connection.workflow` 提供 waiting_login、queued、running、completed、failed、cancelled、interrupted、disconnected 或 account_mismatch 阶段及原因。刷新作品使用 sync_mine，登录失效时重新 connect。

采集使用 `action:"collect",payload:{link:"抖音主页或作品分享链接",more:false}`；继续读取时使用相同链接与 `more:true`。下载或转写使用 `action:"download"` / `"transcribe"`，`payload:{aweme_ids:["作品ID"]}`，每次选择同一账号的 1～30 条作品。

任务状态为 `queued`、`running`、`cancelling`、`cancelled`、`completed`、`partial`、`failed` 或 `interrupted`。连接任务完成仅表示打开或检查动作完成；必须另外读取 `connection.status` 和 `identity` 判断是否已登录。资料读取状态由 `read_state` 表示，不能根据登录成功推断采集成功。首次模型下载取决于本机网络；模型准备和单次浏览器网络操作不能立即取消。

采集只保存实际读取到的公开数据，未知指标为 null，简介不作为转写。Cookie 和带签名的媒体 URL 不进入接口、导出与任务日志。基础研究和单条拆解会创建 AI 交接包，仍需 AI 读取任务、完成分析并回写报告。

业务写入不能缺少空间键。报告的 `source_digest` 是创建时全部来源快照的 SHA-256，回写须与报告一致。完成报告必须保留全部所选作品 ID；这只校验来源关联，不代替人工判断研究质量。

错误响应为 `{error: "可读原因"}`。输入或身份错误 400，Host / Origin / token 错误 403，未知路径 404，数据库不可用 503。

接口只向本机工具开放；不要把会话 token 放到第三方网页，也不要把本服务反向代理到公网。



## AI API 配置与执行

所有研究在本地网页直接通过配置的 AI API 执行。所有写接口继续要求 X-Linsi-Token 和本机来源校验；研究接口要求明确 service_account_key。

| 接口 | 字段与行为 |
| --- | --- |
| GET `/api/ai/config` | 返回 base_url、model、timeout、has_key、configured；永不返回密钥。 |
| POST `/api/ai/config` | base_url、model、api_key、timeout；空密钥保留，clear_key=true 清除。修改地址时要求新密钥或明确清除。允许先留空 model 保存地址以获取列表。 |
| POST `/api/ai/models` | 使用已保存地址和密钥调用 /models，返回模型 ID 列表。 |
| POST `/api/ai/test` | 使用所选模型发送短测试消息，成功返回 ok=true，不提交业务来源。 |
| POST `/api/reports/run-ai` | id、service_account_key；单份报告排队执行，已有完成报告不重复收费，带批次的报告也只排队当前这一份。 |
| POST `/api/reports/cancel-ai` | 仅停止当前报告，不取消同批其他作品，保留素材。 |
| POST `/api/research/confirm` | 确认清单后若 API 已配置，自动开启本批研究。 |
| POST `/api/research/run-ai` | 配置后继续/重试已有批次。 |

研究状态为 awaiting_ai、analyzing、paused、completed。received_chars 是已收到的真实正文字数；phase 表示实际处理阶段，不代表耗时百分比。来源导出仍可用于备份，但不需要人工接手研究。配置文件位于私有数据目录 ai-config.json，不进入公开发布包。


## 批量研究

POST /api/research/create：mode 为 research、breakdown、transcribe、download、comments、refresh；提交 sec_uids 或 aweme_ids，可选 sample_count（1～30）与 refresh=true。相同活动批次去重。

POST /api/research/confirm：提交 id、accounts 列表（sec_uid + items；每项 aweme_id、mode=breakdown/transcribe），可选 comments=true、comment_limit（1～100，默认 30）。每账号最多 30 条、每批最多 100 条、最多 10 个账号。

GET /api/research?id=…：读取逐账号/作品状态、真实子任务和报告入口。GET /api/research/packet?id=…：导出尚未完成报告的来源快照，仅供数据备份和调试，页面执行不依赖人工交接。

POST /api/research/retry：恢复或重试未完成项；POST /api/research/continue：确认以成功作品继续；POST /api/research/cancel：停止本批调度并保留资料；均提交 id 和 service_account_key。GET /api/research/export?id=…：导出已完成结论和所选文案。

批次状态：scanning、review_ready、preparing、partial_ready、awaiting_ai、analyzing、completed、partial、cancelled、interrupted。部分失败与需要恢复明确显示，不把样本准备算作研究完成。
